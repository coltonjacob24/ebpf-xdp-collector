# eBPF XDP Collector

An IPv4 packet-metadata collector using XDP, a BPF ring buffer, Go and InfluxDB 3.

## Metadata-only mode

Records Unix epoch nanoseconds, source/destination IPv4 addresses, TCP/UDP ports,
IP protocol and IPv4 total length. Packet payloads are not retained. Non-initial
IPv4 fragments have zero ports. The initial parser supports Ethernet + IPv4;
IPv6 and VLAN-tagged traffic are not yet included.

Copy `config/config.example.yaml` to `config/config.yaml`, set the interface and
InfluxDB 3 connection values, then build with the Makefile. The process needs the
privileges and kernel support required to attach XDP and load BPF programs.

The InfluxDB writer uses a bounded in-memory queue and batched writes. Queue
overflow and failed database batches are counted but are **data loss**, not durable
buffering. A persistent local spool is required before calling this lossless.

## Performance scope

The ring-buffer implementation is a correctness baseline, not a claim of 50+ Mpps.
A single ring buffer, Go decode and per-event point allocation are likely bottlenecks
at that rate. Reaching the target requires per-RX-queue AF_XDP sockets (zero-copy
where supported), CPU/NUMA pinning, per-queue workers and packet-generator
benchmarks with explicit loss accounting.

## Build

```sh
make clean
make build
```

## Testing
```sh
go test ./...

```

Verbose output
```sh
go test -v ./...
```

To check coverage
```sh
go test -coverage ./...
```

Build requirements include Go, clang/LLVM, libbpf headers and a Linux kernel with
XDP/eBPF support. BPF Go bindings are generated by `go generate ./...`.

## Installing Dependencies (Rocky)
```sh
sudo dnf groupinstall -y "Development Tools"
sudo dnf install -y git make cmake pkgconf-pkg-config
sudo dnf config-manager --set-enabled crb
sudo dnf install -y llvm-toolset
```

sudo dnf install -y \

## Verify Dependencies
```sh
rpm -q libbpf-devel
ls /usr/include/bpf/
pkg-config --exists libbpf && echo "libbpf found" || echo "libbpf NOT found"
clang --version
llvm-config --version
which clang
which llvm-config
```

## Installing Golang
```sh
# Download the latest stable Go (adjust version if needed)
curl -LO https://go.dev/dl/go1.23.4.linux-amd64.tar.gz

# Remove any old Go and install the new one
sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.23.4.linux-amd64.tar.gz

# Add Go to your PATH
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
echo 'export PATH=$PATH:$(go env GOPATH)/bin' >> ~/.bashrc
source ~/.bashrc

# Check version
go version
```
