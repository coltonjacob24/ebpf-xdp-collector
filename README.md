# eBPF XDP Collector

An IPv4 packet-metadata collector using XDP, a BPF ring buffer, Go and InfluxDB 3.

## Metadata-only mode

Records Unix epoch nanoseconds, source/destination IPv4 addresses, TCP/UDP ports,
IP protocol and IPv4 total length. Packet payloads are not retained. Non-initial
IPv4 fragments have zero ports. The initial parser supports Ethernet + IPv4;
IPv6 and VLAN-tagged traffic are not yet included.

Copy `config/config.example.yaml` to `internal/config/config.yaml`, set the interface and
InfluxDB 3 connection values, then build with the Makefile. The process needs the
privileges and kernel support required to attach XDP and load BPF programs.

The InfluxDB writer uses a bounded in-memory queue and batched writes. Queue
overflow and failed database batches are counted but are **data loss**, not durable
buffering. A persistent local spool is required before calling this lossless.

## Performance scope

The ring-buffer implementation is a correctness baseline, not a claim of 50+ Mpps.
A single ring buffer, Go decode and per-event point allocation are likely bottlenecks
at that rate. Reaching the target requires per-RX-queue AF_XDP sockets (zero-copy
where supported), CPU/NUMA pinning, per-queue workers and packet-generator
benchmarks with explicit loss accounting.

## Build And Run

### Ensure InfluxDB is up and running:
```sh
sudo systemctl status influxdb3-core
sudo systemctl start influxdb3-core

# Enable automatic startup (only needs to be done once):
sudo systemctl enable influxdb3-core

# Verify the database listens on port 8181
sudo ss -lntp | grep 8181
# Expected endpoint is http://localhost:8181

# Optional: Load environment variables:
~/.config/ebpf-xdp-collector/influx.env

## ~/.config/ebpf-xdp-collector/influx.env contains
export INFLUX_TOKEN='YOUR_ADMIN_TOKEN'
export INFLUXDB3_AUTH_TOKEN="$INFLUX_TOKEN"
export INFLUX_URL='http://localhost:8181'
##
source ~/.config/ebpf-xdp-collector/influx.env
echo "$INFLUX_URL"
```
If a fresh install of InfluxDB 3 is needed, see Installing Dependencies (Rocky).

### Verify Database
```sh
# Collector writes packet metadata to packet_metadata DB
# Check if it exists and can be accessed
influxdb3 query \
  --host http://localhost:8181 \
  --database packet_metadata \
  "SHOW TABLES"

# Check current record count with:
influxdb3 query \
  --host http://localhost:8181 \
  --database packet_metadata \
  "SELECT COUNT(*) AS total FROM packet_event"
```

### Run Collector
```sh
make clean
make all

# Optional step to verify executable:
ls -lh bin/collector

# Run
sudo -E ./bin/collector
```

## Testing

### Go
```sh
# Go unit tests
go test -v ./...

# Go race detector
go test -race ./...

# Go static analysis
go vet ./...

# C packet parser tests
make test-c

# Full test suite
make test
```

### C/XDP parser test starter

Files:
- bpf/xdp_collector.h
- bpf/packet_parser.h
- bpf/xdp_collector.c
- bpf/tests/packet_parser_test.c

The parser is shared between the XDP program and host-side C tests.

To run the test:
```sh
make test-c
make build
go test -race ./...
```

### C to Go Compatibility Test
```sh
# Run Test
make generate-event

# Check Output
wc -c bin/packet_event.bin
# Expected Output: 32 bin/packet_event.bin
```

The host tests execute the same parse_ipv4_packet() function
used by the XDP program.

They validate parsing behavior and the 32-byte event ABI.

They do not yet load the program into the kernel or test
ring-buffer delivery.

That privileged integration test is a separate next stage.


## Installing Dependencies (Rocky)

Build requirements include Go, clang/LLVM, libbpf headers and a Linux kernel with
XDP/eBPF support. BPF Go bindings are generated by `go generate ./...`.


```sh
sudo dnf groupinstall -y "Development Tools"
sudo dnf install -y git make cmake pkgconf-pkg-config
sudo dnf config-manager --set-enabled crb
sudo dnf install -y llvm-toolset
```

```sh
sudo dnf install -y \
  kernel-devel \
  kernel-headers \
  elfutils-libelf-devel \
  zlib-devel \
  libbpf \
  libbpf-devel \
  bpftool \
  clang \
  llvm \
  llvm-devel
```

### Verify Dependencies
```sh
rpm -q libbpf-devel
ls /usr/include/bpf/
pkg-config --exists libbpf && echo "libbpf found" || echo "libbpf NOT found"
clang --version
llvm-config --version
which clang
which llvm-config
```

### Installing InfluxDB 3
```sh
sudo dnf update -y

sudo dnf install -y \
  git \
  make \
  clang \
  llvm \
  gcc \
  gcc-c++ \
  libbpf-devel \
  bpftool \
  iproute \
  iputils \
  python3 \
  curl \
  wget \
  tar

# influxdb3-core
curl --silent --location -O \
  https://repos.influxdata.com/influxdata-archive.key

gpg --show-keys --with-fingerprint --with-colons \
  ./influxdata-archive.key 2>&1 \
  | grep -q '^fpr::*24C975CBA61A024EE1B631787C3D57159FC2F927:$'

# If successful:
sudo mkdir -p \
  /usr/share/influxdata-archive-keyring/keyrings

sudo cp influxdata-archive.key \
  /usr/share/influxdata-archive-keyring/keyrings/influxdata-archive.asc

sudo tee /etc/yum.repos.d/influxdata.repo > /dev/null <<'EOF'
[influxdata]
name = InfluxData Repository - Stable
baseurl = https://repos.influxdata.com/stable/$basearch/main
enabled = 1
gpgcheck = 1
gpgkey = file:///usr/share/influxdata-archive-keyring/keyrings/influxdata-archive.asc
EOF

# Install
sudo dnf install -y influxdb3-core
influxdb3 --version

# Configure
/etc/influxdb3/influxdb3-core.conf
sudo nano /etc/influxdb3/influxdb3-core.conf

# Add:
node-id = "primary-node"
object-store = "file"
data-dir = "/var/lib/influxdb3/data"
plugin-dir = "/var/lib/influxdb3/plugins"

# Enable automatic start
sudo systemctl enable influxdb3-core

# Start service
sudo systemctl start influxdb3-core
sudo systemctl status influxdb3-core
sudo ss -lntp | grep 8181

# Create initial token:
influxdb3 create token --admin

# Securely store token
mkdir -p ~/.config/ebpf-xdp-collector
chmod 700 ~/.config/ebpf-xdp-collector
nano ~/.config/ebpf-xdp-collector/influx.env

## Add:
export INFLUX_TOKEN='PASTE_YOUR_NEW_ADMIN_TOKEN_HERE'
export INFLUXDB3_AUTH_TOKEN="$INFLUX_TOKEN"
export INFLUX_URL='http://localhost:8181'
##

chmod 600 ~/.config/ebpf-xdp-collector/influx.env
source ~/.config/ebpf-xdp-collector/influx.env

# Verify without displaying token:
echo "$INFLUX_URL"

if [ -n "$INFLUX_TOKEN" ]; then
    echo "InfluxDB token loaded"
fi

# Optional code to automatically load the file upon opening a terminal
echo 'source ~/.config/ebpf-xdp-collector/influx.env' >> ~/.bashrc
#

source ~/.bashrc

# Create packet_metadata
influxdb3 create database \
  --host http://localhost:8181 \
  packet_metadata

# Verify existence
influxdb3 show databases \
  --host http://localhost:8181

# Verify access
influxdb3 query \
  --host http://localhost:8181 \
  --database packet_metadata \
  "SHOW TABLES"
```
